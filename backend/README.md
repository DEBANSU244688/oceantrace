# OceanTrace backend

FastAPI service implementing the pipeline in `SACD.md`. Verified end-to-end:
detection recovers the ground-truth spill location, hindcast recovers the
ground-truth origin and spill window, and attribution correctly ranks the
"guilty" vessel above the near-miss/false-positive/clean vessels with
explainable reasons.

## Setup
```bash
pip install -r requirements.txt
```

## Generate demo data (run once, or whenever the scenario constants in
`app/config.py` change)
```bash
python scripts/generate_ais.py             # synthetic AIS roster + tracks
python scripts/generate_sample_image.py    # synthetic SAR-style demo image
```
Both scripts print a verification table/summary — check it before moving on.
**Swap in a real Zenodo SAR image before the actual round if time allows**:
replace `data/sample_images/sar_001.png` + its `_meta.json` bounding box,
and add an entry to `SAMPLE_IMAGES` in `app/config.py`. `detector.py` doesn't
care which image it's given.

## Run
```bash
uvicorn app.main:app --reload --port 8000
```
Interactive API docs (auto-generated from the Pydantic schemas): http://localhost:8000/docs

## Project layout
```
app/
  config.py        single source of truth for the demo scenario constants
  geo_utils.py      shared lat/lon <-> km math
  detector.py       classical CV: threshold + morphology + contour selection
  characterize.py   pixel contour -> polygon geometry + stats
  drift_engine.py   particle advection, backward (hindcast) & forward (forecast)
  attribution.py    AIS funnel + weighted scoring + "why flagged" reasons
  store.py          in-memory state (see DB.md — no DB server needed)
  schemas.py        pydantic models = the API contract, typed
  main.py           FastAPI app + endpoints
scripts/
  generate_ais.py           builds data/vessels.json + data/ais_positions.csv
  generate_sample_image.py  builds data/sample_images/sar_001.png + bbox
data/                (generated by the two scripts above — not hand-edited)
```

## Sanity-check the pipeline without the frontend
```bash
python -c "
from app import store, drift_engine, attribution, config
store.load_ais_data()
hc = drift_engine.hindcast(config.DETECTED_LAT, config.DETECTED_LON)
print('origin:', hc.center, 'vs ground truth:', config.ORIGIN_LAT, config.ORIGIN_LON)
"
```
Or hit http://localhost:8000/docs and try each endpoint by hand.
